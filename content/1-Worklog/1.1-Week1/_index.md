### Week 1 Achievements

* **Program integration and teamwork:** Connected with the mentors and five team members, learned about each person's technical strengths, and agreed on communication channels, progress updates, and ways of working. This helped me understand my responsibilities in a technical team and become more proactive when discussing blockers.

* **Understanding the internship roadmap:** Gained a clear understanding of the requirements, rules, expected deliverables, and learning plan from June 22, 2026, to August 15, 2026. I divided the roadmap into weekly milestones so that I could track progress, prioritize tasks, and prepare learning materials in advance.

* **Setting up an AWS Workshop development environment:** Installed and used Hugo, Markdown, and Visual Studio Code to run the workshop website locally. I learned the purpose of the `content` and `static` directories, the Hugo configuration file, and the bilingual Vietnamese/English content structure, allowing me to update pages without breaking the site's organization.

* **Presenting architecture with draw.io:** Became familiar with AWS Architecture Icons and used draw.io to represent the components of a cloud system. I learned to group resources into logical layers, illustrate connections between services, and arrange diagrams so that the architecture is easy to understand.

* **Building cloud computing and AWS foundations:** Understood core cloud characteristics such as elasticity, on-demand resource provisioning, and pay-as-you-go pricing. I also learned the differences between Regions, Availability Zones, and Edge Locations and understood the roles of Compute, Storage, Networking, and Database services in an AWS architecture.

* **Using AWS management tools:** Learned to navigate the AWS Management Console, locate services, and inspect resource information. I configured the AWS CLI, selected a working Region, and used basic commands to verify the configuration, account information, and running resources.

* **Practicing Amazon EC2 fundamentals:** Understood the roles of Instance Types, Amazon Machine Images (AMIs), Key Pairs, Elastic Block Store (EBS), and Elastic IPs. I launched an EC2 instance, connected to it through SSH, and attached an EBS volume, which gave me a practical understanding of the basic lifecycle of a virtual server on AWS.

* **Defining the initial project direction:** The team identified the main functions of a facial skin-care E-commerce platform and discussed research areas such as the AI model, database, and security. This provided a foundation for selecting suitable AWS services and designing the system architecture in later weeks.

> **Overall result:** By the end of the first week, I had integrated into the FCAJ program, completed the workshop development setup, and established an initial AWS foundation. More importantly, I progressed from simply recognizing service names to understanding their roles in a cloud architecture and performing basic operations through both the Console and CLI.
